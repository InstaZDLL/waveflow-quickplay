# WaveFlow QuickPlay 1.0.0

The first release of the small player that sits next to WaveFlow: double-click a track, hear it now, with the desktop app's own decoders in a window the size of a notification.

## What it does

- **Plays every format WaveFlow plays**: MP3, FLAC, WAV, AIFF, Vorbis, Opus, AAC, ALAC, DSF and DFF, through the same codec registry, resampler and lock-free ring as the desktop engine.
- **Opens in a quarter of a second**, audio engine created on the first play, one 31 MB executable.
- **Two sizes**: a compact bar with clock, title, format, spectrum, seek and transport, or the cover above it, freely resizable.
- **A playlist window docked to the player**: it follows it, minimizes and restores with it, and shares its taskbar entry.
- **Synced lyrics** from a `.lrc` next to the file, the current line in place of the title; long lines scroll.
- **One instance per user**: launching another file hands it to the open player, `--enqueue` appends.
- **File-manager integration**: *Play with WaveFlow QuickPlay* and *Add to WaveFlow QuickPlay playlist* in the Explorer context menu and an "Open with" entry, installed for the current user; a desktop entry with the audio MIME types on Linux.
- **Eight languages**: English, French, German, Spanish, Italian, Simplified Chinese, Japanese and Korean. The system language is used by default; the gear in the title bar opens a settings page to pick another, with the about block (version, licence, repository) under it. The Explorer entries follow the chosen language.

Deliberately not in scope: EQ, crossfade, gapless, ReplayGain, device selection and exclusive output. Those live in WaveFlow Desktop.

## Install

- **Windows**: download `waveflow-quickplay_1.0.0_x64-setup.exe`. It installs for the current user without administrator rights and registers the context-menu entries; uninstalling removes them.
- **Linux**: the `.deb` for Debian and Ubuntu, or the `.AppImage` for any distribution (make it executable and run it). Both carry the desktop entry, so QuickPlay appears in "Open with" for audio files.
- **macOS**: no bundle or installer for this release. The player was checked from a locally built binary on macOS 26 (Apple silicon): playback, the docked playlist, minimize and restore from the Dock, the single instance. Build it with `cargo build --release` (needs Xcode's command line tools and `cmake`).

SHA-256 checksums are in `SHA256SUMS-windows.txt` and `SHA256SUMS-linux.txt`.

> [!NOTE]
> The Windows installer is signed with WaveFlow's self-signed certificate, so Windows may still show a SmartScreen warning on first launch.

## Known limitations

- On Wayland the playlist window opens where the compositor places it and does not follow the player; the protocol does not let an application position its windows.
- The output device is the system default, opened in shared mode.
