# WaveFlow QuickPlay 1.6.0

Your audio files now look like WaveFlow files when QuickPlay is their default player.

## New

- **An icon per format on Windows**: once QuickPlay is the default player for a format, its files show a WaveFlow document with the format on it (FLAC, MP3, WAV, AIFF, Ogg, Opus, M4A, MP4, AAC, DSF, DFF, M3U, M3U8), in every Explorer view, as a badge on cover thumbnails, and in the file's properties. The *Type* column says "FLAC audio file" and so on, in QuickPlay's language.
- **QuickPlay in Settings › Default apps on Windows**: it is listed there with every format it plays, so it can be made the default player for each one in one place. *Open with › Always use this app* works too. QuickPlay still never makes itself the default: that stays your choice.
- **Format icons on macOS**: once QuickPlay is the default player for a format (*Get Info › Open with › Change All*), its files get the same WaveFlow document icon. DSF and DFF files show it everywhere in Finder. For the formats macOS knows itself (FLAC, MP3, AAC, playlists…), Finder keeps its own icon in the icon and list views and shows QuickPlay's in the *Get Info* window: that is Finder's choice, not something an app can change.

## Install

- **Windows**: download `waveflow-quickplay_1.6.0_x64-setup.exe`. It installs for the current user without administrator rights and registers the context-menu entries, the per-format icons and the Default apps entry. Run it over an earlier version to upgrade; your settings live in their own file and are kept.
- **Linux**, on x86_64 (`amd64`, `x86_64` in the file name) or Arm (`arm64`, `aarch64`): the `.deb` for Debian and Ubuntu, the `.rpm` for Fedora, RHEL and openSUSE, or the `.AppImage` for any distribution (make it executable and run it). The `.deb` and the `.rpm` install the desktop entry, so QuickPlay appears in *Open with* for audio files and playlists. An AppImage installs nothing: run it once with `--register` for the same entry.
- **macOS**: download `waveflow-quickplay_1.6.0_macos-universal.dmg`, open it and drag *WaveFlow QuickPlay* to Applications. The app is signed ad hoc, not by an Apple Developer ID, so macOS blocks the first launch: open System Settings › Privacy & Security and choose *Open Anyway* (on macOS 14 and earlier, right-click the app and choose *Open*).

1.2.0 to 1.5.0, installed from the Windows installer, the macOS app or an AppImage, update themselves to 1.6.0: they download it at launch and install it when you close QuickPlay. That takes *Check for updates at launch*, at the bottom of the settings page, which is on unless you turned it off. If it is off, either turn it back on and start QuickPlay again (the check runs only at launch), or install 1.6.0 by hand. 1.0.0 and 1.1.0 do not look for updates, so they are upgraded by hand once.

SHA-256 checksums are in `SHA256SUMS-windows.txt`, `SHA256SUMS-linux.txt` (x86_64), `SHA256SUMS-linux-aarch64.txt` and `SHA256SUMS-macos.txt`. `latest.json` is what the updater reads: it lists the packages that update themselves (the Windows installer, the macOS app and the two AppImages), each with its signature.

> [!NOTE]
> The Windows installer is signed with WaveFlow's self-signed certificate, so Windows may still show a SmartScreen warning on first launch.

## Known limitations

- **Already made QuickPlay your default player on Windows?** Pick it again for each format (Settings › Default apps, or *Open with › Always use this app*) to get the new icons. Windows keeps the choice you made before, which points at an entry with one icon for every format, and no app may change that choice for you.
- **On macOS** the icons show only once QuickPlay is the default player for a format, and, for the formats macOS knows itself, only in the *Get Info* window (see above).
- **Linux** has no per-format icons: a file's icon there comes from the icon theme, whatever the default player, so QuickPlay leaves it alone.
- A `.deb`, an `.rpm` and a copy run from a read-only place (the disk image itself, or an app macOS runs from a translocated copy because it was not moved to Applications) are never replaced by QuickPlay: they only say that a new version is out.
